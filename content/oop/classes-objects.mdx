A `class` bundles state and behavior. Constructor parameters go right in the class signature:

```scala
class Person(val name: String, var age: Int):
  def greet(): String = s"Hi, I'm $name"

val p = Person("Ada", 30)
println(p.greet())
p.age = 31
println(p.age)
```

`val name` in the parameter list creates a read-only field; `var age` creates a mutable one.
Create instances with `Person(...)` — no `new` keyword needed in modern Scala.
