---
title: Traits
summary: Interfaces with implementation, mixins.
---

A `trait` is like a Java interface, but it can also hold concrete method implementations and
state. Classes can mix in multiple traits with `extends` and `with`:

```scala
trait Greeter:
  def name: String
  def greet(): String = s"Hello, $name!"  // default implementation

class English(val name: String) extends Greeter

val g = English("Ada")
println(g.greet())
```

Traits are how Scala achieves the benefits of multiple inheritance without its usual pitfalls —
each trait contributes behavior, and the compiler linearizes them predictably.
