---
title: Case Classes
summary: Value semantics, equality, and copy.
---

A `case class` is a regular class with extra conveniences generated automatically — the natural
choice for data that's mostly about *what it holds*, not custom behavior:

```scala
case class Point(x: Int, y: Int)

val a = Point(1, 2)
val b = Point(1, 2)

println(a == b)        // true — compared by value, not identity
println(a)              // Point(1,2) — readable toString for free
val c = a.copy(y = 9)   // Point(1,9) — copy with one field changed
println(c)
```

You get, for free: a public constructor, `equals`/`hashCode` based on the fields, a readable
`toString`, and `.copy(...)` for making a modified duplicate without mutation. Case classes also
work directly with `match`:

```scala
def onAxis(p: Point): String = p match
  case Point(0, 0) => "origin"
  case Point(_, 0) => "on x-axis"
  case Point(0, _) => "on y-axis"
  case _           => "elsewhere"
```
