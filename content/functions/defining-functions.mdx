---
title: Defining Functions
summary: def, parameters, return types.
---

Functions are defined with `def`, a name, parameters, and a return type. The return type can
usually be inferred, but it's good practice to write it explicitly for anything public:

```scala
def add(a: Int, b: Int): Int =
  a + b

println(add(2, 3))
```

There's no `return` keyword needed — the last expression in the function body is the result.
Multi-line bodies use a block:

```scala
def square(x: Int): Int =
  val result = x * x
  result
```
