---
title: Higher-Order Functions
summary: Functions that take or return functions.
---

Because functions are values in Scala, you can pass one function as an argument to another. A
function that does this is called a **higher-order function**:

```scala
def applyTwice(f: Int => Int, x: Int): Int =
  f(f(x))

val increment: Int => Int = x => x + 1
println(applyTwice(increment, 5))  // 7
```

`Int => Int` is a **function type**: "a function from Int to Int." This is the pattern behind
`map`, `filter`, and every other collection operation you'll learn in the *Collections* module.
