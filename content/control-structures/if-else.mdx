---
title: If/Else as Expressions
summary: Why if/else returns a value in Scala.
---

In most languages `if` is a statement — it controls flow but doesn't produce a value. In Scala,
`if`/`else` is an **expression**: it evaluates to a value you can assign directly.

```scala
val age = 20
val category = if age >= 18 then "adult" else "minor"
println(category)
```

There's no separate ternary operator (`? :`) in Scala — `if`/`else` already does that job, and
reads more clearly. An `if` without an `else` implicitly returns `Unit` in the missing branch.
