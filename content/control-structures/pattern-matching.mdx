---
title: Pattern Matching
summary: match expressions, guards, and destructuring.
---

`match` is Scala's most-used control structure — think of it as a `switch` that can destructure
data, not just compare values:

```scala
def describe(x: Int): String = x match
  case 0          => "zero"
  case n if n < 0 => "negative"
  case _          => "positive"

println(describe(-5))
```

Each `case` is tried top to bottom. `case _` is the wildcard — "match anything else." A
`case n if n < 0` is a **guard**: it only matches when the condition after `if` also holds.

<TryIt initialCode={`def describe(x: Int): String = x match\n  case 0          => "zero"\n  case n if n < 0 => "negative"\n  case _          => "positive"\n\nprintln(describe(-5))\nprintln(describe(0))\nprintln(describe(42))`} />

`match` also works on tuples, lists, and case classes (you'll see that combination in the
*Case Classes* lesson) — it's the backbone of idiomatic Scala.
