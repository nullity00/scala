Every Scala file with a top-level `@main` method is directly runnable. This is the modern
(Scala 3) way to write an entry point — no boilerplate `object ... extends App` required:

```scala
@main def hello(): Unit =
  println("Hello, World!")
```

<TryIt initialCode={`@main def hello(): Unit =\n  println("Hello, World!")`} />

`println` writes a line to standard output. You'll use it constantly while learning — it's the
simplest way to see what a piece of code actually produces.

### The REPL

Scala also has a **REPL** (Read-Eval-Print Loop) — an interactive shell where you type an
expression and immediately see its value. Every "Try it Yourself" box in this course behaves like
a REPL session: it runs your code and shows the result instantly.
