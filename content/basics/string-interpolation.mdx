---
title: String Interpolation
summary: s-strings, f-strings, and raw strings.
---

Prefixing a string literal with `s` lets you embed expressions directly inside it using `$`:

```scala
val name = "Ada"
val age = 30
println(s"$name is $age years old")
println(s"Next year: ${age + 1}")
```

Use `${ }` when the expression is more than a single identifier. There's also an `f`-interpolator
for `printf`-style formatting:

```scala
val price = 19.999
println(f"Total: $$${price}%.2f")
```
