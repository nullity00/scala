---
title: Data Types
summary: Int, Double, Boolean, Char, String, Unit, Any.
---

Scala's basic types map closely to Java's primitives, but they're all real objects with methods:

| Type      | Example         | Notes                                  |
|-----------|-----------------|-----------------------------------------|
| `Int`     | `42`            | 32-bit signed integer                   |
| `Long`    | `42L`           | 64-bit signed integer                   |
| `Double`  | `3.14`          | 64-bit floating point                   |
| `Boolean` | `true`, `false` |                                          |
| `Char`    | `'a'`           | single character                        |
| `String`  | `"hello"`       | not primitive, but used constantly      |
| `Unit`    | `()`            | like `void` — "no meaningful value"     |

Scala almost always **infers** the type from the value you assign, so you rarely write it out —
but you can always be explicit:

```scala
val age: Int = 30
val price: Double = 19.99
val isReady: Boolean = true
```
